# oblivionsoft

The public pages for Oblivion Soft games (Adam Allen), served by GitHub Pages at
https://dyluckneo.github.io/oblivionsoft/

| Page | URL | Used by |
|---|---|---|
| Home | `/` | Play Console "Website" field |
| LineGods privacy policy | `/linegods/privacy/` | Play Console, LineGods About screen |
| Beamwright privacy policy | `/beamwright/privacy/` | Play Console, Beamwright Settings |

Each game keeps the same text as Markdown in its own `store/privacy_policy.md`; change both
together and update the "Last updated" date. Plain HTML and one stylesheet, no build step
(`.nojekyll` turns off GitHub's Jekyll processing).
